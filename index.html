Sistema de Pré-Alertas

Este sistema foi desenvolvido para facilitar a geração de pré-alertas para liberação de motoristas nas empresas clientes.

Como funciona:

1. Clique no botão "Fazer Pré-Alerta" abaixo

2. Selecione o motorista e a data de entrega

3. Opcionalmente, adicione números de pedido para GRUs

4. Clique em "Gerar Pré-Alerta"

5. O sistema irá gerar um e-mail formatado com todas as informações necessárias

6. Copie o conteúdo e cole em seu e-mail no Outlook
